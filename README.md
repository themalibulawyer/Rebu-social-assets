# RE-BU Social Assets

Public host for RE-BU's branded social-post images, so Metricool can fetch them by direct URL.

## How to use a card's URL
Each PNG has a permanent raw URL:
`https://raw.githubusercontent.com/themalibulawyer/rebu-social-assets/main/<path>`

Example (steel-framing tip):
`https://raw.githubusercontent.com/themalibulawyer/rebu-social-assets/main/tips/tip_01.png`

Paste that URL as the image/media on a Metricool post and it fetches it server-side.

## Folders
- `tips/` — the 12 evergreen weekly rebuild-tip cards (tip_01–tip_12), 1080x1080.
- `posts/` — dated campaign cards (Expo run-up, directory/fire-wise/roundup cards, featured-partner cards).
